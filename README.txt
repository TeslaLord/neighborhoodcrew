The Neighborhood Crew - static website
=======================================
Open index.html in any browser. No install, no build step.

index.html   main page
hello.html   short landing page (good for the QR code on a flyer or door hanger)
css/style.css   all styling (colours are the variables at the top)
js/main.js      quote form -> opens a text message
images/         photos and logo

To host: upload this whole folder to Netlify, Cloudflare Pages, GitHub Pages
or any web host. Make sure index.html stays at the top level.

Things to fill in later:
- Google review link: search for YOUR-REVIEW-LINK in index.html
- Real reviews: replace the "collecting our first reviews" paragraph in index.html
